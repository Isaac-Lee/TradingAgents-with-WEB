# Card 08 — E2E 수동 검증 + 보드 문서 마감

**Blocked by:** Card 07

## 배경

`00-BOARD.md`의 "완료 후" 절: 모든 카드 Done 이후 전체 플로우를 한 번 수동으로
확인하고 결과를 문서에 남긴다.

## 작업

1. `python -m webapp.desktop` (또는 서버+브라우저)로 전체 플로우 수동 확인:
   - 런 시작 → 실시간 상태/로그 → 완료 뱃지+리포트 탭 → 정지 버튼 동작
   - 히스토리 목록 → 과거 리포트 열기 → 2개 비교
   - 차트 탭
2. 결과(확인 항목별 pass/fail, 환경, 발견 이슈)를 `00-BOARD.md` 말미에
   "완료 검증 기록" 섹션으로 추가.
3. 발견된 버그는 새 카드로 등록 (이 카드에서 고치지 않는다 — 문서화 카드).

## Acceptance

- [ ] 위 플로우 각 항목이 실제로 실행되고 결과가 `00-BOARD.md`에 기록됨.
- [ ] `pytest tests/` 최종 통과.
- [ ] `git status` 기준 의도치 않은 변경/잔여 파일 없음.

## 금지

- 이 카드에서 기능 수정 (발견 이슈는 별도 카드).
